# Сладкие Сны — бронирование номеров (PHP + MySQL)

## Запуск
1. Импортировать `sql/schema.sql` (создаёт БД `hotel`, таблицы и тестовые номера).
2. Проверить доступ к БД в `config.php` (DB_USER / DB_PASS).
3. Положить папку в корень веб-сервера (OpenServer/XAMPP: `htdocs`/`domains`) и открыть `index.php`.

## Страницы
- `index.php` — каталог, фильтр по категории на сервере, 6 случайных номеров
- `order.php?room=ID` — бронирование, серверная валидация, календарь занятости
- `login.php` / `logout.php` — вход администратора (hotel123 / adminHotel)
- `admin.php` — заявки: одобрить / удалить

## Безопасность
PDO + подготовленные запросы, экранирование вывода (htmlspecialchars), CSRF-токены,
действия администратора только через POST, `session_regenerate_id` при входе,
строгая проверка дат/телефона/email/имён на сервере, транзакция против двойной брони.
